들어가기: 객체란?

비유스마트폰을 떠올려 보세요. 색상과 저장 용량 같은 특징이 있고, 전화 걸기와 사진 찍기 같은 할 수 있는 일이 있죠. 자바스크립트의 객체는 이 둘을 하나의 꾸러미로 묶어 둔 것이에요.

현실자바스크립트
스마트폰 한 대객체 (object)
색상, 저장 용량속성 (property)
전화 걸기메서드 (method)
스마트폰 설계도생성자 함수 / 클래스

아래 예제의 ▶ 실행 버튼을 눌러 보세요. 코드를 직접 고친 뒤 실행해도 돼요.

1. 객체 만들기

비유학생증을 만든다고 생각해요. 빈 카드에 이름: 값 형태로 정보를 하나씩 적는 거예요.

  1. 중괄호 { }로 객체를 만들어요.
  2. 안에 이름: 값을 쉼표(,)로 구분해 적어요.
  3. 값에는 문자, 숫자, 배열, 다른 객체도 넣을 수 있어요.
  4. 읽을 때는 객체.이름 또는 객체['이름']을 써요.
{ name: '민지', age: 15, scores: [ 90, 85, 100 ] }
민지
15

2. 속성

비유학생증 정보는 고치고, 새 칸을 만들고, 지울 수 있어요. 객체의 속성도 똑같이 읽기·바꾸기·추가·삭제가 가능해요.

{ name: '나비', age: 3, color: '흰색' }
false
[ 'name', 'age' ]
주의const로 만든 객체도 안의 속성은 바꿀 수 있어요. const는 변수에 다른 객체를 다시 넣는 것만 막아요. 아래 실습에서 직접 바꿔 보세요.

3. 메서드

비유자판기의 버튼처럼, 누르면 동작하는 기능이에요. 값이 함수인 속성을 메서드라고 불러요. 실행하려면 이름 뒤에 괄호 ()를 꼭 붙여요.

계산기를 켰어요!
5
[Function: add]

4. this

비유"내 이름은 ~입니다"라는 문장은 말하는 사람에 따라 뜻이 달라져요. this는 지금 이 메서드를 부른 객체, 즉 "나"를 가리켜요.

내 이름은 콩이입니다
내 이름은 나비입니다
this를 잃어버렸어요!
주의메서드를 객체에서 떼어 내면 this를 잃어버려요. 필요하면 dog.introduce.bind(dog)로 묶어 주세요. 또 객체의 메서드를 화살표 함수(=>)로 만들면 this가 객체를 가리키지 않으니 피하세요.

5. 생성자 함수

비유붕어빵 틀이에요. 틀 하나로 같은 모양의 붕어빵(객체)을 여러 개 찍어 내요. 이름은 관례로 대문자로 시작하고, new와 함께 불러요.

  1. new가 빈 객체를 만들어요.
  2. 함수 안의 this가 그 새 객체를 가리켜요.
  3. 속성을 채운 뒤 완성된 객체를 돌려줘요.
Person { name: '민지', age: 15 }
준호
true

6. 클래스

비유같은 붕어빵 틀을 더 읽기 쉬운 새 설계도 양식으로 쓴 거예요. constructor는 객체가 만들어질 때 자동으로 실행되는 특별한 메서드예요.

민지은(는) 이제 16살!
Person { name: '민지', age: 16 }

7. 상속

비유부모의 재산을 물려받는 것과 같아요. 동물의 공통 기능을 강아지가 물려받고, 필요한 부분만 새로 만들거나 덮어써요. extends로 물려받고, super로 부모를 불러요.

콩이: 냠냠 밥을 먹어요
콩이: 멍멍!
Dog { name: '콩이', breed: '푸들' }
true
주의자식 constructor에서는 this를 쓰기 전에 반드시 super()를 먼저 불러야 해요.

8. 프로토타입

비유학교 도서관이에요. 학생마다 같은 책을 사지 않고, 도서관(프로토타입)에 한 권을 두고 모두가 빌려 봐요. 객체에 없는 속성은 자기 것 → 부모(프로토타입) → 그 위 부모 순서로 찾아 올라가요.

예: a → Person.prototype → Object.prototype → null (앞의 상속, 클래스도 이 원리로 움직여요.)
