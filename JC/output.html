JavaScript 출력문 기초 학습

자바스크립트 데이터를 화면이나 사용자가 확인할 수 있는 곳에 출력하는 4가지 대표적인 방법을 알아봅니다.

1. 전체 소스 코드 구조

아래는 학습할 전체 기본 HTML 구조입니다.

<!DOCTYPE html>
<html>
<head>
    <title>예제8-6 출력문</title>
</head>
<body>
<h1>JavaScript Output</h1>
<p id="output">outPut2:innerHTML</p>
    <script>
        document.write("outPut1:write");  
        // document.write() : HTML 문서에 직접 문자열 출력

        document.getElementById("output").innerHTML = "outPut2:innerHTML";  
        // innerHTML : 특정 요소(id="output") 안에 내용 삽입

        window.alert("outPut3:alert");  
        // alert : 팝업 창으로 메시지 출력

        console.log("outPut4:console");  
        // console.log : 브라우저 개발자 도구 콘솔에 메시지 출력
    </script>
</body>
</html>

2. 4가지 출력 방식 상세 설명

① document.write()

설명: HTML 문서에 직접 문자열을 출력합니다. 웹페이지 로드가 끝난 후에 실행되면 기존 문서 내용이 모두 지워지고 출력될 수 있어 주로 테스트 용도로 사용합니다.

출력 결과 영역:

대기 중

② innerHTML

설명: 지정한 HTML 요소(예: id="output")의 내부에 새로운 문자열이나 태그를 삽입합니다. 가장 흔하게 사용하는 실무적인 방식입니다.

대상 요소 (<p id="target-p">): outPut2:innerHTML

③ window.alert()

설명: 브라우저 상단에 팝업 창(대화상자)을 띄워 사용자에게 메시지를 전달합니다. 확인 버튼을 누를 때까지 다음 코드가 멈춥니다. (window 생략 가능)

④ console.log()

설명: 일반 화면에는 보이지 않고, 브라우저의 개발자 도구(F12) - Console 탭에 기록됩니다. 프로그램 디버깅(오류 확인)에 필수적입니다.

* 버튼을 누른 후 브라우저 개발자 도구 콘솔창을 확인하세요.

3. 요약 비교 표

출력 방식 출력 위치 주요 용도
document.write() HTML 문서 본문 단순 테스트
innerHTML 지정한 HTML 요소 내부 웹페이지 콘텐츠 동적 변경 (실무 중심)
window.alert() 브라우저 경고 팝업창 중요 알림 전달
console.log() 개발자 도구 콘솔창 디버깅 및 데이터 확인
