JavaScript 조건문과 반복문

조건문은 조건에 따라 다른 코드를 실행하고, 반복문은 같은 코드를 여러 번 실행합니다. 각 버튼을 눌러 예제를 확인해 보세요.

한눈에 보기
  • if, else if, else, switch: 조건에 따라 실행할 코드를 선택합니다.
  • for, while, do while: 조건이나 횟수에 따라 코드를 반복합니다.

1. if else

if 조건이 참이면 첫 번째 코드를, 거짓이면 else 코드를 실행합니다.

if (temperature >= 20) {
    message = "따뜻해요.";
} else {
    message = "선선해요.";
}
°C

2. else if

여러 조건 중 어떤 조건이 참인지 차례로 검사합니다. 처음으로 참이 된 조건의 코드만 실행합니다.

if (score >= 90) {
    grade = "A";
} else if (score >= 80) {
    grade = "B";
} else {
    grade = "C";
}

3. switch

하나의 값이 여러 경우 중 어떤 값과 같은지 비교할 때 사용합니다. 일치하는 case를 실행하고 break로 빠져나옵니다.

switch (day) {
    case "월요일":
        message = "한 주의 시작!";
        break;
    case "금요일":
        message = "주말이 가까워요!";
        break;
    default:
        message = "좋은 하루 보내세요!";
}

4. for

반복 횟수가 정해져 있을 때 편리합니다. 아래 코드는 숫자 1부터 5까지 출력합니다.

for (let i = 1; i <= 5; i++) {
    numbers.push(i);
}

5. while

조건이 참인 동안 반복합니다. 조건을 바꾸는 코드가 없으면 반복이 끝나지 않을 수 있으니 주의하세요.

let i = 1;
while (i <= 3) {
    numbers.push(i);
    i++;
}

6. do while

do 블록을 먼저 한 번 실행한 뒤 조건을 확인합니다. 그래서 조건이 처음부터 거짓이어도 한 번은 실행됩니다.

let i = 1;
do {
    numbers.push(i);
    i++;
} while (i <= 3);
