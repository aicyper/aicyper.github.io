예제 1 · 객체 속성 + 메서드

학생 성적 관리 도구

학생 객체에 이름과 과목 점수를 저장하고, 메서드로 평균을 계산합니다. 실제 성적표나 학습 관리 페이지의 기본 구조와 비슷합니다.

입력 및 실행

점수를 입력하고 성적 계산을 눌러 보세요.

핵심 코드

const student = {
  name: '민지',
  scores: { 국어: 90, 수학: 85, 영어: 100 },
  average() {
    const values = Object.values(this.scores);
    return values.reduce((sum, n) => sum + n, 0) / values.length;
  }
};

포인트: scores는 중첩 객체이고, average()는 메서드입니다. 메서드 안의 this.scores는 호출한 student 객체의 점수를 가리킵니다.

예제 2 · 객체 배열 + 속성 변경

온라인 쇼핑 장바구니

상품을 객체로 표현하고, 상품 객체 여러 개를 배열에 담습니다. 수량을 변경하거나 상품을 추가·삭제하면 합계가 다시 계산됩니다.

상품 추가

장바구니 현황

상품가격수량금액관리
총 합계: 0원
상품 종류: 0개

핵심 코드

const cart = {
  items: [],
  add(product) { this.items.push(product); },
  total() {
    return this.items.reduce((sum, item) => sum + item.price * item.quantity, 0);
  }
};

포인트: items는 객체 배열입니다. reduce()는 각 상품의 가격 × 수량을 누적해 합계를 구합니다. 실제 결제 기능을 만들 때는 서버에서도 가격을 검증해야 합니다.

예제 3 · 클래스 + 상속 + 메서드 재정의

게임 캐릭터 상태 시뮬레이터

공통 상태를 가진 캐릭터 클래스를 만들고, 전사와 마법사가 이를 상속합니다. 공격 버튼을 누르면 캐릭터별 메서드가 실행되고 HP가 변합니다.

전사

HP: 100 / 100

마법사

HP: 80 / 80

전투 기록

전투 준비 완료! 공격 버튼을 눌러 보세요.

핵심 코드

class Character {
  constructor(name, hp) { this.name = name; this.hp = hp; }
  takeDamage(amount) { this.hp = Math.max(0, this.hp - amount); }
}
class Warrior extends Character {
  attack(target) { target.takeDamage(15); }
}
class Mage extends Character {
  attack(target) { target.takeDamage(22); } // 공격 방식 확장
}

포인트: extends로 공통 기능을 상속하고, 각 클래스에 다른 공격력을 정의했습니다. 여기서는 메서드를 재정의하는 대신 각 하위 클래스에 고유한 attack()을 추가했습니다.
