JavaScript 함수 알아보기

함수는 특정 작업을 수행하도록 작성한 코드 묶음입니다. 한 번 만들어 두면 필요할 때 여러 번 실행할 수 있습니다.

기본 문법 
function 함수이름(매개변수) {
    // 실행할 코드
    return 결과값;
}

함수이름(전달값);

매개변수는 함수에 전달되는 값을 받는 변수이고, return은 함수의 결과를 돌려줍니다.

1. 이벤트 함수

이벤트 함수(이벤트 처리 함수)는 클릭, 입력, 키보드 입력처럼 사용자의 동작이 일어났을 때 실행됩니다. 아래 버튼을 누르면 클릭 횟수가 늘어납니다.

let count = 0;

function countClick() {
    count = count + 1;
    result.textContent = count + "회 클릭했습니다.";
}

button.addEventListener("click", countClick);
아직 클릭하지 않았습니다.

2. 함수로 하는 연산

함수에 숫자와 연산자를 전달하고, 함수 안에서 계산한 뒤 return으로 결과를 돌려줄 수 있습니다.

function calculate(a, b, operator) {
    if (operator === "+") return a + b;
    if (operator === "-") return a - b;
    if (operator === "*") return a * b;
    if (operator === "/") return a / b;
}

3. 내장 함수

prompt, confirm, alert를 이용해 경고창 처럼 사용할 수 있습니다.

  • prompt("내용","예시내용"): 사용자에게 입력을 받는 창을 띄웁니다.
  • confirm("내용"): 사용자에게 확인을 요청하는 창을 띄웁니다.
  • alert("내용"): 사용자에게 알림을 표시하는 창을 띄웁니다.
