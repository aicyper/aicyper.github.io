JavaScript 선언문

변수를 선언하는 var, let, const의 차이와 산술·대입·비교 연산자를 직접 실행해보며 정리합니다.

변수 선언 — var / let / const

variable declaration

변수를 선언하는 키워드는 여러 개가 있지만, 가장 기본이 되는 세 가지만 다룹니다. 같은 이름을 다시 선언하거나 값을 다시 대입했을 때 어떻게 반응하는지 버튼으로 직접 확인해보세요.

var
var x = 1;
var x = 2;  // 재선언 OK
x = 3;      // 재대입 OK
결과 표시
let
let y = 1;
// let y = 2; // 재선언 X (에러)
y = 3;      // 재대입 OK
결과 표시
const
const z = 1;
// const z = 2; // 재선언 X
// z = 3;        // 재대입도 X (에러)
결과 표시
키워드재선언재대입스코프
var가능가능함수 스코프
let불가능가능블록 스코프
const불가능불가능블록 스코프 (선언과 동시에 초기화 필수)

산술 연산자

arithmetic operators

더하기, 빼기, 곱하기, 나누기, 나머지, 거듭제곱 여섯 가지를 x, y 두 값에 대해 어떻게 쓰는지 정리했습니다. 아래 두 숫자를 넣고 계산하면 결과가 바로 표시됩니다.

문법
x + y   // 더하기
x - y   // 빼기
x * y   // 곱하기
x / y   // 나누기
x % y   // 나머지
x ** y  // 거듭제곱
x + y—
x - y—
x * y—
x / y—
x % y—
x ** y—
※ 참고
  • JavaScript에는 몫만 따로 구하는 전용 연산자가 없습니다. (다른 언어의 //, div 같은 것이 없음)
  • 몫이 필요하면 Math.floor(x / y)로 나눈 값을 내림해서 구합니다.

대입 연산자

assignment operators

기본 대입(=)에 산술 연산을 합쳐 줄여 쓰는 방식입니다. x += y는 x = x + y와 같습니다.

연산자같은 표현
x += yx = x + y
x -= yx = x - y
x *= yx = x * y
x /= yx = x / y
x %= yx = x % y
x **= yx = x ** y
직접 눌러 값이 바뀌는 걸 확인 — 현재 값 10

비교 연산자

comparison operators

두 값을 비교해 true/false를 돌려줍니다. == 와 != 는 타입을 바꿔서라도 비교하고(느슨한 비교), === 와 !== 는 타입까지 같아야 true입니다(엄격한 비교).

연산자의미
==값이 같음 (타입 변환 허용)
===값과 타입이 모두 같음
!=값이 다름 (타입 변환 허용)
!==값 또는 타입이 다름
> / <크다 / 작다
>= / <=크거나 같다 / 작거나 같다
직접 비교해보기
a, b 값을 입력하고 연산자를 눌러보세요 (예: a=1, b="1" 일 때 == 와 === 결과가 다릅니다)

증감 연산자

increment / decrement

값을 1씩 늘리거나 줄입니다. 연산자를 앞에 쓰느냐(전위) 뒤에 쓰느냐(후위)에 따라 "먼저 반환하는 값"이 다릅니다.

연산자이름동작
x++후위 증가기존 값을 먼저 반환하고 나서 1 증가
++x전위 증가1 증가시킨 후 그 값을 반환
x--후위 감소기존 값을 먼저 반환하고 나서 1 감소
--x전위 감소1 감소시킨 후 그 값을 반환
현재 x = 5
버튼을 누르면 "반환값 / 변경 후 x" 가 표시됩니다

논리 연산자

logical operators

true/false 값을 조합합니다. &&는 둘 다 참일 때만, ||는 하나라도 참이면 true이고, !는 값을 반대로 뒤집습니다.

연산자의미
a && ba 그리고 b — 둘 다 참이어야 true
a || ba 또는 b — 하나만 참이어도 true
!aa의 반대값
a, b 값을 켜고 꺼서 비교해보기
a, b를 토글하고 연산자를 눌러보세요

삼항 연산자

ternary operator

if/else를 한 줄로 줄인 표현입니다. 조건 ? 참일 때 값 : 거짓일 때 값 형태로 씁니다.

문법
x % 2 === 0 ? '짝수' : '홀수'
숫자를 넣고 판별을 눌러보세요

비트 연산자

bitwise operators

숫자를 2진수로 바꿔 비트 단위로 연산합니다. 일반적인 로직보다는 저수준 계산이나 플래그 처리에 가끔 쓰입니다.

연산자의미
a & bAND — 둘 다 1인 자리만 1
a | bOR — 하나라도 1이면 1
a ^ bXOR — 서로 다르면 1
~aNOT — 비트를 반전
a << n왼쪽으로 n비트 이동 (2ⁿ 곱하기와 비슷)
a >> n오른쪽으로 n비트 이동 (부호 유지)
직접 계산해보기
a & b—
a | b—
a ^ b—
~a—
a << 1—
a >> 1—
