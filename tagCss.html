🌐 CSS 실습 파일 목록

  • 1. CSS를 외부로 스타일을 적용
    CSS파일을 HTML파일과 분리해서 만든 후 연결시킴
  • 2. CSS를 내부에서 스타일을 적용
    HTML파일 내부안에 style태그로 적용시킴
  • 3. CSS를 태그 안에서 인라인으로 스타일을 적용
    HTML파일 내부안에 각 태그들 안에서 style요소를 이용해 적용시킴
  • 4.타입 선택자로 스타일을 적용
    타입 선택자를 이용해 여러 스타일을 적용시킴
  • 5.AI를 이용해 CSS의 6개의 선택자
    css의 여러 내용들을 정리시킴
  • 6.AI를 이용해 text의 여러구조를 정리
    text의 여러 디테일 구조들을 구성
  • 7.AI를 이용해 테두리와 박스정리
    테두리의 구조들과 박스와 패딩을 정리
  • 8.AI를 이용해 레이아웃을 구성
    레이아웃의 구성 요소들을 정리
