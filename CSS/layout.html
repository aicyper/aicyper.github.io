header

<header>

페이지나 섹션의 머리말을 담습니다.

  • 로고, 사이트 제목
  • 검색 바, 슬로건
  • 페이지 상단 고정 영역
<header>
  <h1>My Site</h1>
  <img src="logo.png" alt="로고">
</header>
🧭

nav

<nav>

사이트의 주요 내비게이션 링크 모음입니다.

  • 상단 메뉴, 사이드 메뉴
  • 목차(Table of Contents)
  • 보조 링크엔 사용 자제
<nav>
  <a href="/">홈</a>
  <a href="/blog">블로그</a>
</nav>
📄

section

<section>

주제별로 콘텐츠를 논리적으로 묶는 구역입니다.

  • 보통 제목(h2~h6)을 포함
  • 단순 스타일 묶음엔 div 사용
  • 여러 section 중첩 가능
<section>
  <h2>최신 뉴스</h2>
  <!-- 관련 콘텐츠 -->
</section>
📝

article

<article>

페이지에서 독립적으로 배포·재사용될 수 있는 콘텐츠입니다.

  • 블로그 포스트, 뉴스 기사
  • 댓글, 포럼 글
  • RSS 피드로 그대로 내보낼 수 있는 단위
<article>
  <h3>글 제목</h3>
  <p>본문 내용...</p>
</article>
📌

aside

<aside>

본문과 간접적으로 연관된 부가 콘텐츠입니다.

  • 사이드바, 관련 글 목록
  • 광고, 위젯, 인용구
  • 없어도 본문 이해에 지장 없음
<aside>
  <h4>관련 글</h4>
  <ul>...</ul>
</aside>

  • 이용약관, 개인정보 링크
  • section·article 안에도 사용 가능
<footer>
  <p>© 2025 My Site</p>
  <a href="/privacy">개인정보</a>
</footer>
