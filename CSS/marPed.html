Margin & Padding

HTML 요소의 간격을 제어하는 두 가지 CSS 속성입니다.

margin
border
padding
content

Margin — 요소 바깥 여백

요소와 주변 요소 사이의 간격입니다. 배경색이 적용되지 않는 투명한 공간입니다.

margin: 0

Box A
Box B

margin: 16px (사방 동일)

Box A
Box B

margin-top: 24px  /  margin-left: 48px

Box A

Padding — 요소 안쪽 여백

요소의 테두리(border)와 내용(content) 사이의 간격입니다. 배경색이 적용됩니다.

padding: 0

Box A

padding: 16px (사방 동일)

Box A

padding-top: 24px  /  padding-left: 48px

Box A

Shorthand 문법

margin과 padding은 값의 개수에 따라 방향이 결정됩니다.

작성 방식적용 방향
margin: 10px상·우·하·좌 모두 10px
margin: 10px 20px상하 10px  /  좌우 20px
margin: 10px 20px 30px상 10px  /  좌우 20px  /  하 30px
margin: 10px 20px 30px 40px상 10 / 우 20 / 하 30 / 좌 40 (시계 방향)

※ padding도 동일한 shorthand 규칙이 적용됩니다.
