스타일 적용 방법

💡 HTML 코드 주요 구성 요소 설명

  • <link type="text/css" rel="stylesheet" href="color.css"> (외부 스타일시트 연동): 이 문서의 핵심 부분입니다. 같은 폴더(또는 지정된 경로)에 있는 color.css라는 별도의 CSS 파일을 불러와 이 HTML 문서의 스타일(색상, 글꼴, 레이아웃 등)을 제어합니다.
  • <div id="menu"> (메뉴 영역 분리): 상단 메뉴 역할을 하는 부분을 id="menu"로 지정하여 그룹화했습니다. CSS에서 #menu라는 선택자를 통해 이 영역만 특별한 스타일을 적용할 수 있도록 준비해둔 상태입니다.
  • <a> 태그와 target="_blank" (하이퍼링크): 메뉴 내부의 세 가지 링크(하이퍼링크, 추가된 폼 속성, 비디오)는 target="_blank" 속성이 설정되어 있어, 클릭 시 현재 창이 아닌 새 탭(혹은 새 창)에서 열리게 됩니다.
  • &nbsp; (공백 문자): 메뉴의 링크 글자들 사이에 일정한 공백(띄어쓰기)을 주기 위해 HTML 특수 문자인 &nbsp;를 사용했습니다.

요약 및 특징: 이 HTML 문서는 본문 내에 직접적인 색상이나 디자인 코드가 전혀 없습니다. 대신 웹페이지의 구조(뼈대)만 다루고 있으며, 실제 시각적인 디자인은 연결된 color.css 파일이 전적으로 담당하도록 깔끔하게 분리된 전형적인 웹 표준 방식으로 작성되었습니다.
