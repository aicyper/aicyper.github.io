CSS Position

요소의 배치 방식을 결정하는 position 속성. 5가지 값을 예제와 함께 확인하세요.

static 기본값

모든 요소의 기본 position 값입니다. 문서의 일반 흐름(normal flow)에 따라 배치되며, top / right / bottom / left 속성이 적용되지 않습니다.

Box 2 — static
Box 3 — static

relative 상대 위치

원래 있어야 할 위치를 기준으로 이동합니다. 이동 후에도 원래 자리는 그대로 유지되어, 주변 요소의 배치에 영향을 주지 않습니다.

Box 1 — 이동 없음
원래 자리 (유지됨)
Box 2 — top:12px; left:24px
Box 3 — 이동 없음

absolute 절대 위치

가장 가까운 position: relative/absolute/fixed 조상 요소를 기준으로 배치됩니다. 문서 흐름에서 완전히 빠져나와 원래 자리를 차지하지 않습니다.

부모 요소 position: relative

absolute — bottom:8px; right:8px

fixed 고정 위치

뷰포트(브라우저 창)를 기준으로 배치됩니다. 스크롤해도 항상 같은 위치에 고정됩니다. 우측 하단의 주황색 버튼이 fixed 예제입니다.

→ 화면 오른쪽 아래를 보세요. 스크롤해도 고정된 버튼이 바로 position: fixed 요소입니다.

.btn {
  position: fixed;
  bottom: 24px;
  right: 24px;
}

sticky 끈끈한 고정

스크롤 위치에 따라 static ↔ fixed 처럼 동작합니다. 지정한 임계값(top 등)에 도달하기 전에는 normal flow를 따르고, 도달하면 그 자리에 고정됩니다. 상단 내비게이션 바도 sticky로 구현되어 있습니다.

5가지 값 비교

값 기준점 문서 흐름 스크롤 영향
static 없음 (기본 흐름) 유지 같이 움직임
relative 자기 원래 위치 유지 (자리 보존) 같이 움직임
absolute 가장 가까운 non-static 조상 이탈 같이 움직임
fixed 뷰포트 이탈 고정 (스크롤 무관)
sticky 스크롤 컨테이너 유지 → 임계값 도달 시 고정 임계값까지는 움직임, 이후 고정
