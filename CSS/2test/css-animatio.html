CSS Animation

@keyframes로 시작·중간·끝 상태만 정의하면 브라우저가 그 사이를 자동으로 채워 움직임을 만듭니다. 아래 예시들은 모두 정지 상태로 대기하다가, 마우스가 박스에 닿으면 실행됩니다.

색상 애니메이션 — color animation

background-color, opacity

@keyframes 안에서 background-color나 opacity 값을 단계별로 지정하면, 브라우저가 그 사이의 색을 자동으로 계산해 부드럽게 이어줍니다. 마우스를 박스에 올리면 실행되고, 떼면 그 자리에서 멈춥니다.

color
마우스를 올리면 시작
animation: colorShift 4s linear infinite; 파랑 → 초록 → 빨강 → 파랑 순으로 배경색이 순환
opacity
마우스를 올리면 시작
animation: fadeInOut 2s ease-in-out infinite alternate; opacity 1 → 0.15를 오가며 서서히 사라졌다 나타남
CSS — 색상 순환 예시
@keyframes colorShift {
  0%   { background-color: #25507f; }  /* 시작 키프레임 */
  33%  { background-color: #2f7a4f; }  /* 중간 키프레임 */
  66%  { background-color: #b7402e; }
  100% { background-color: #25507f; }  /* 시작색으로 되돌아와 자연스럽게 이어짐 */
}

.box {
  animation: colorShift 4s linear infinite;
  animation-play-state: paused;   /* 평소엔 정지 상태로 대기 */
}
.stage:hover .box {
  animation-play-state: running;  /* 마우스가 닿으면 실행 */
}
colorShift
@keyframes로 정의한 이름. animation에서 이 이름을 불러 사용합니다.
0% ~ 100%
전체 재생 시간을 비율로 나눈 지점. 각 지점의 색만 적으면 사이 색은 브라우저가 계산합니다.
4s
한 번 도는 데 걸리는 시간(duration). 이 값이 없으면 애니메이션이 보이지 않습니다.
linear
속도 곡선. 색이 일정한 속도로 바뀝니다.
infinite
반복 횟수. 끝나지 않고 계속 순환합니다.
alternate
opacity 예시에 쓰인 값으로, to까지 간 뒤 반대로 되돌아옵니다.

이동 애니메이션 — 위치 변화

transform: translate

키 프레임마다 translate 값을 다르게 주면 요소가 그 지점들을 따라 움직입니다. 중간 경로는 브라우저가 자동으로 계산하는 중간 프레임(인터폴레이션)입니다. 마우스를 올리면 움직이기 시작합니다.

slideX
마우스를 올리면 시작
animation: slideX 2.4s ease-in-out infinite alternate; 좌우로 왕복 이동 — alternate로 되돌아옴
bounceY
마우스를 올리면 시작
animation: bounceY 1.8s ease-in-out infinite; 위아래로 튀는 듯한 상하 이동
path
마우스를 올리면 시작
animation: pathMove 5s linear infinite; 0·25·50·75·100% 키프레임으로 사각 경로를 순회
CSS — 이동 예시
/* 좌우 왕복 : 시작(from)과 끝(to) 두 지점만 지정 */
@keyframes slideX {
  from { transform: translateX(-70px); }
  to   { transform: translateX(70px); }
}
.box { animation: slideX 2.4s ease-in-out infinite alternate; }

/* 사각 경로 : 네 모서리를 %로 찍어 순서대로 이동 */
@keyframes pathMove {
  0%   { transform: translate(-70px, -40px); }  /* 좌상 */
  25%  { transform: translate( 70px, -40px); }  /* 우상 */
  50%  { transform: translate( 70px,  40px); }  /* 우하 */
  75%  { transform: translate(-70px,  40px); }  /* 좌하 */
  100% { transform: translate(-70px, -40px); }  /* 다시 좌상 */
}
.box { animation: pathMove 5s linear infinite; }
from / to
0%와 100%를 뜻하는 다른 표기. 두 지점만 필요할 때 더 간결합니다.
translateX / translate
left·top 대신 transform으로 옮기면 레이아웃을 다시 계산하지 않아 더 부드럽습니다.
ease-in-out
시작과 끝이 느려 자연스럽게 방향을 바꾸는 느낌을 줍니다.
alternate
to까지 간 뒤 역방향으로 되돌아옵니다. 없으면 끝에서 시작 위치로 순간이동합니다.
100%를 0%와 같게
경로를 닫아두면 반복될 때 튀지 않고 매끄럽게 이어집니다.

반복 애니메이션 — iteration-count

animation-iteration-count

같은 회전 애니메이션에 반복 횟수만 다르게 지정했습니다. 숫자를 쓰면 그 횟수만큼만 실행되고, infinite를 쓰면 멈추지 않고 계속 반복됩니다. 마우스를 올려 실행한 뒤, 정해진 횟수가 끝나면 더 이상 움직이지 않는 것을 확인할 수 있습니다.

1회
마우스를 올리면 시작
animation: spin 1.6s ease-out 1 forwards; 한 바퀴만 돌고 정지
3회
마우스를 올리면 시작
animation: spin 1.6s linear 3 forwards; 세 바퀴 돈 뒤 정지
무한
마우스를 올리면 시작
animation: spin 1.6s linear infinite; 끝나지 않고 계속 회전
CSS — 반복 횟수 비교
@keyframes spin {
  from { transform: rotate(0deg); }
  to   { transform: rotate(360deg); }
}

/* 같은 keyframes를 쓰고 반복 횟수만 다르게 지정 */
.once     { animation: spin 1.6s ease-out 1 forwards; }
.three    { animation: spin 1.6s linear  3 forwards; }
.infinite { animation: spin 1.6s linear  infinite; }
1 / 3 / infinite
animation-iteration-count 자리. 숫자만큼 실행하거나, infinite면 멈추지 않습니다.
forwards
animation-fill-mode. 끝난 뒤 마지막 상태를 유지시켜 처음 각도로 되돌아가지 않게 합니다.
0deg → 360deg
한 바퀴. 시작과 끝 모습이 같아 반복해도 이음매가 보이지 않습니다.
paused / running
animation-play-state. 진행 위치를 기억하므로 다시 올리면 멈춘 지점부터 이어집니다.

CSS3 애니메이션 핵심 요약

애니메이션의 개념, 기본 구성과 주요 속성을 정리했습니다.

■ 1. 애니메이션(Animation)

요소의 위치, 크기, 색상, 회전 등을 시간에 따라 변화시키는 기능
JavaScript 없이 CSS만으로 구현 가능

■ 2~4. 프레임 관련 용어

프레임 (Frame)
애니메이션을 구성하는 하나의 정지 화면
키 프레임 (Key Frame)
사용자가 직접 지정하는 중요한 시점(시작, 중간, 끝) — @keyframes 규칙으로 정의
중간 프레임 (In-between)
브라우저가 키 프레임 사이를 자동 계산하여 생성 — 인터폴레이션(Interpolation) 또는 트위닝(Tweening)

■ 5. 애니메이션 기본 구성

@keyframes 이름 { from { 시작 상태 } to { 종료 상태 } }

■ 6. animation 단축 속성

animation: 이름 지속시간 속도곡선 지연시간 반복횟수 방향 채움모드 실행상태;

■ 7. 주요 속성

속성역할
@keyframes키 프레임 정의
animation모든 속성의 단축형
animation-name사용할 키 프레임 이름
animation-duration실행 시간
animation-delay시작 지연 시간
animation-timing-function속도 변화(ease, linear 등)
animation-iteration-count반복 횟수(infinite 가능)
animation-direction실행 방향(normal, reverse, alternate)
animation-fill-mode종료 후 스타일 유지 여부
animation-play-staterunning / paused

■ 8. 기억하기

Transition
상태 변화가 있을 때만 실행
Animation
상태 변화 없이도 자동 실행 가능

■ 9. 애니메이션 흐름

시작 (Key Frame)
↓
중간 프레임 (자동 생성)
↓
종료 (Key Frame)
