personal study notes

CSS Transform

이동(translate), 기울이기(skew), 확대·축소(scale) 세 가지 2D 변형을 좌표 격자 위에서 비교합니다. 점선 상자는 원래 위치, 색이 있는 상자는 transform이 적용된 결과입니다.

이동 — translate()

translate · translateX · translateY

요소를 원래 자리에서 x축·y축 방향으로 밀어 이동시킵니다. 레이아웃 흐름에는 영향을 주지 않고 시각적 위치만 바뀝니다.

box
translate(100px, 200px)x, y 동시 이동
box
translateX(150px)x축만 이동
box
translateY(-50px)y축만 이동

기울이기 — skew()

skew · skewX · skewY

사각형의 변을 지정한 각도만큼 비스듬히 기울입니다. 첫 번째 값은 x축 기준, 두 번째 값은 y축 기준 기울기입니다.

box
skew(20deg, 0)x축 기준 기울임
box
skew(0, 20deg)y축 기준 기울임
box
skew(20deg, 20deg)x, y축 동시 기울임

회전 — rotate()

rotate

요소를 지정한 각도만큼 시계 방향(양수) 또는 반시계 방향(음수)으로 회전시킵니다. 기본 기준점은 요소의 중심입니다.

box
rotate(30deg)시계 방향 30도
box
rotate(-45deg)반시계 방향 45도
box
rotate(180deg)180도 반전

확대·축소 — scale()

scale · scaleX · scaleY

요소의 가로·세로 크기를 배수로 조정합니다. 1보다 작으면 축소, 크면 확대되며 중심점을 기준으로 커지거나 작아집니다.

box
scale(0.5, 0.5)가로·세로 50% 축소
box
scaleX(1.5)가로만 150% 확대
box
scaleY(1.5)세로만 150% 확대
