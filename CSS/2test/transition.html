CSS Transition

속성이 바뀌는 과정을 순간적인 변화가 아니라 자연스러운 흐름으로 보여줍니다. hover로 색상·크기 변화를 직접 확인하고, timing-function에 따라 속도 곡선이 어떻게 달라지는지 비교합니다.

hover 시 색상·크기 변화

background-color, transform + transition

마우스를 블록 위에 올리면 background-color와 transform(scale)이 동시에 바뀝니다. transition이 없으면 색과 크기가 즉시 바뀌지만, transition을 걸어두면 그 변화가 부드럽게 이어집니다.

마우스를 올려보세요
hover me
transition: background-color 0.35s ease, transform 0.35s ease; hover 시 background-color가 바뀌고 transform: scale(1.12)로 살짝 커짐

속도 곡선 — timing-function

transition-timing-function

timing-function은 transition의 세 번째 값으로, 시작부터 끝까지 속도가 어떻게 변하는지를 정합니다. 아래 점들은 모두 같은 거리를 같은 시간(1.9s) 동안 왕복하지만, 곡선이 달라 움직이는 느낌이 다릅니다.

linear 일정한 속도로 이동
ease 기본값 — 천천히 시작해 빨라졌다가 다시 천천히
ease-in 천천히 시작해서 점점 빨라짐
ease-out 빠르게 시작해서 점점 느려짐
ease-in-out 시작과 끝 모두 느리고 중간만 빠름
cubic-bezier(n,n,n,n) 직접 정의한 곡선 — 예시는 끝에서 튕기는 효과

CSS Transition 핵심 요약

transition의 개념과 기본 문법, 구성 요소를 정리했습니다.

■ transition

CSS 속성 변경을 부드러운 애니메이션으로 표현
hover, click 등의 효과에 자주 사용

■ 기본 문법

transition: property duration timing-function delay;

■ 구성 요소

구성 요소역할
property변경할 CSS 속성
duration실행 시간(s, ms)
timing-function속도 변화(ease, linear, ease-in, ease-out 등)
delay시작 지연 시간
예) transition: all 0.5s ease;
※ 핵심
  • transition은 스타일 변화를 자연스럽게 만든다.
  • duration이 없으면 애니메이션 효과가 나타나지 않는다.
