예제 01 — font-family & font-size
font-family serif / sans / mono
Nanum Myeongjo (serif)
Noto Sans KR (sans-serif)
Courier New (monospace)

글꼴 계열(serif·sans-serif·monospace)을 지정합니다. 콤마로 폴백 글꼴을 나열합니다.

font-family: 'Nanum Myeongjo', serif; font-size: 18px;
font-weight & font-style 굵기·기울기
Light 300 Bold 700
italic 기울임 oblique 20°

font-weight는 100~900의 숫자 또는 bold/normal로 지정합니다. font-style은 normal·italic·oblique를 지원합니다.

font-weight: 700; font-style: italic; font-style: oblique 20deg;

color: #b5451b; /* 주황-갈색 */ color: #2a9d8f; /* 틸 그린 */ color: #7b3f9e; /* 보라 */ background-color: #e9c46a; /* 샌드 옐로 */
예제 04 — text-shadow
Hard Shadow
하드 섀도우

블러 없이 offset만 지정하면 선명한 그림자가 생깁니다.

text-shadow: 2px 2px 0 #1a1209;
Soft Glow
소프트 글로우

블러 반경을 크게 하면 부드러운 광택 효과.

text-shadow: 0 2px 8px rgba(0,0,0,.55);
Neon & Multi
Neon Glow
Multi Layer

여러 그림자를 쉼표로 중첩 적용합니다.

text-shadow: 0 0 6px #39ff14, 0 0 14px #00ff88;

예제 05 — text-decoration
Decoration 종류 밑줄·윗줄·취소선
underline — 빨간 실선 밑줄
overline wavy — 물결 윗줄
line-through double — 이중 취소선
underline + overline dotted

text-decoration은 line·style·color·thickness를 한 번에 축약 지정할 수 있습니다.

text-decoration: underline; text-decoration-color: #e63946; text-underline-offset: 3px; text-decoration: overline wavy #2a9d8f; text-decoration: line-through double #e9c46a;
text-transform 대소문자 변환
uppercase: hello world → HELLO WORLD
lowercase: Hello World → hello world
capitalize: hello world → Hello World
full-width: abc → ａｂｃ

HTML 소스 값을 변경하지 않고 시각적 표현만 바꿉니다. SEO나 접근성에는 영향을 주지 않습니다.

text-transform: uppercase; text-transform: lowercase; text-transform: capitalize; text-transform: full-width;
예제 07 — letter-spacing & word-spacing
letter-spacing 자간
자간 넓게 4px → A B C D
자간 좁게 -1px → 압축된느낌

양수 값은 글자 간격을 넓히고, 음수 값은 좁힙니다. em 단위 사용 권장.

letter-spacing: 4px; letter-spacing: -1px; letter-spacing: 0.1em;
word-spacing 단어 간격
단어 간격 넓히기 word spacing 12px

단어(공백) 사이의 추가 간격을 지정합니다. px·em·normal을 사용합니다.

word-spacing: 12px; word-spacing: 0.5em; word-spacing: normal;
예제 08 — text-align & direction
정렬 방향 + RTL text-align · direction
text-align: left — 왼쪽 정렬 (기본값)
text-align: right — 오른쪽 정렬
text-align: center — 가운데 정렬
text-align: justify — 양쪽 정렬. 긴 문장일 때 좌우 여백을 맞춰줍니다. 신문·잡지 레이아웃에 자주 사용됩니다.
direction: rtl — 오른쪽→왼쪽 (아랍어·히브리어 등)

direction 속성은 텍스트 흐름의 기본 방향을 결정하며, unicode-bidi와 함께 사용합니다.

text-align: justify; direction: rtl; /* Right To Left */ unicode-bidi: bidi-override;
예제 09 — line-height & text-indent
line-height 행간

행간 1.2 — 줄 간격이 좁아 밀도 있는 텍스트 블록을 만듭니다. 제목이나 캡션에 적합합니다.

행간 2.0 — 줄 간격이 넓어 읽기 편한 본문 텍스트에 적합합니다.

단위 없는 숫자(예: 1.6)가 가장 안전합니다. 자식 요소에서 font-size에 비례해 계산됩니다.

line-height: 1.2; line-height: 2; line-height: 1.6; /* 본문 권장 */
text-indent 들여쓰기

text-indent: 20px — 단락의 첫 번째 줄만 들여씁니다. 인쇄물의 단락 표기 방식과 동일합니다.

음수 값을 사용하면 내어쓰기(hanging indent)가 됩니다. % 단위도 사용 가능합니다.

text-indent: 20px; text-indent: 2em; text-indent: -1em; /* 내어쓰기 */
예제 10 — writing-mode & text-orientation
세로쓰기 writing-mode · text-orientation
세로쓰기
vertical-lr
세로 왼→오
竪組
writing-mode는 텍스트가 흐르는 방향을 결정합니다.
· horizontal-tb — 가로 (기본값)
· vertical-rl — 세로, 오른쪽→왼쪽
· vertical-lr — 세로, 왼쪽→오른쪽

text-orientation은 세로쓰기 모드에서 글자 방향을 결정합니다.
· mixed — 한글·한자는 세로, 라틴 문자는 눕힘
· upright — 모든 문자를 세로 그대로 표시
· sideways — 모든 문자를 90° 회전
writing-mode: vertical-rl; text-orientation: mixed; writing-mode: vertical-lr; text-orientation: upright;
