CSS3 선택자
완전 가이드

선택자는 스타일을 적용할 HTML 요소를 지정하는 패턴입니다. CSS3는 강력한 선택자 문법을 제공합니다.

▸ 6가지 핵심 선택자  |  실시간 데모 포함

SELECTOR 01 / 06

전체 선택자

Universal Selector — 문서의 모든 요소 선택

*

설명

* 선택자는 HTML 문서 내 모든 요소에 스타일을 일괄 적용합니다. 주로 CSS 리셋이나 box-sizing 전역 설정에 사용합니다. 성능상 이유로 남용은 지양하고 필요한 경우에만 씁니다.

/* 모든 요소의 기본 여백 초기화 */ * { margin: 0; padding: 0; box-sizing: border-box; }

라이브 데모

* 선택자로 아래 모든 요소에 동일한 테두리 적용됨

div em strong code small

SELECTOR 02 / 06

자식 결합자

Child Combinator — 직계 자식 요소만 선택

A > B

설명

A > B는 A의 바로 아래(직계) 자식 B만 선택합니다. 후손 선택자(A B)와 달리 더 깊이 중첩된 요소는 선택하지 않아 스타일 범위를 정밀하게 제어할 수 있습니다.

/* .parent의 직계 li만 파란색 */ .parent > li { background: #e8f0ff; color: steelblue; } /* 중첩 li는 영향받지 않음 */

라이브 데모

  • 직계 자식 — 파란 배경 적용 ✓
    • 손자 요소 — 적용 안 됨
    • 손자 요소 — 적용 안 됨
  • 직계 자식 — 파란 배경 적용 ✓

SELECTOR 03 / 06

속성 선택자

Attribute Selector — 특정 속성 값을 가진 요소 선택

[attr]

설명

요소의 HTML 속성을 기준으로 선택합니다. [type="text"]처럼 정확한 값, [href^="https"]처럼 시작값, [src$=".png"]처럼 끝값 매칭도 가능합니다.

/* type="text" 입력창만 초록 테두리 */ input[type="text"] { border: 1.5px solid green; } /* href가 https로 시작하는 링크 */ a[href^="https"] { color: royalblue; }

라이브 데모

→ 같은 input 태그지만 type 속성으로 다르게 스타일링

SELECTOR 04 / 06

구조 가상 클래스

Structural Pseudo-class — 위치 기반으로 요소 선택

:nth-child

설명

부모 안에서의 순서(위치)를 기준으로 요소를 선택합니다. :nth-child(odd)는 홀수 번째, (even)은 짝수 번째, (3n+1)처럼 수식도 가능합니다. 테이블 줄무늬 같은 패턴에 자주 씁니다.

/* 홀수 번째 li만 보라색 배경 */ li:nth-child(odd) { background: #f5eaff; color: purple; } /* 세 번째 요소마다 선택 */ li:nth-child(3n) { ... }

라이브 데모

  • 01 — 홀수 번째 (보라 배경)
  • 02 — 짝수 번째
  • 03 — 홀수 번째 (보라 배경)
  • 04 — 짝수 번째
  • 05 — 홀수 번째 (보라 배경)
  • 06 — 짝수 번째

SELECTOR 05 / 06

가상 요소

Pseudo-elements — HTML 없이 요소 앞뒤에 콘텐츠 삽입

::before / ::after

설명

::before와 ::after는 선택한 요소의 내용 앞·뒤에 가상 콘텐츠를 CSS만으로 삽입합니다. 반드시 content 속성이 있어야 하며, 장식적 요소나 아이콘 삽입에 활용합니다.

.quote::before { content: '"'; font-size: 2.5rem; color: goldenrod; } .quote::after { content: ' — CSS3'; font-size: 0.8rem; display: block; }

라이브 데모

content 속성으로 HTML 없이 콘텐츠를 삽입할 수 있습니다

SELECTOR 06 / 06

인접 형제 결합자

Adjacent Sibling Combinator — 바로 다음 형제 요소 선택

A + B

설명

A + B는 A 바로 다음에 오는 첫 번째 형제 요소 B를 선택합니다. 같은 부모를 가지며 A 바로 직후에 위치한 경우에만 적용됩니다. 폼 레이블·입력 후 에러 메시지, 아코디언 등에 응용됩니다.

/* .highlight 바로 다음 li만 파란색 */ .highlight + li { background: #e0f3ff; color: steelblue; } /* 두 칸 이상 떨어진 형제는 해당 없음 */

라이브 데모

  • 첫 번째 항목
  • 두 번째 항목
  • ★ .highlight 클래스 (기준 요소)
  • 바로 다음 형제 → 파란 배경 적용 ✓
  • 두 번째 형제 → 적용 안 됨
