HTML 레이아웃 기초

Block 요소와 Inline 요소

HTML 요소는 렌더링 방식에 따라 크게 두 종류로 나뉩니다. 각각의 특성과 대표 태그를 예제와 함께 살펴보세요.

Block 블록 요소
블록 요소는 항상 새 줄에서 시작하며, 가로 전체 너비를 차지합니다. 위아래로 다른 요소와 구분되는 독립적인 공간을 형성하고, width, height, margin, padding 등 모든 박스 모델 속성을 완전히 지원합니다.
새 줄에서 시작 width: 100% (기본) width / height 설정 가능 margin / padding 완전 지원 내부에 block & inline 포함 가능

<div>
div — 범용 컨테이너. 레이아웃 구성에 가장 많이 쓰입니다.
<p>
p — 단락 요소. 위아래에 기본 마진이 자동으로 생깁니다.

주요 Block 태그

<div> <p> <h1> ~ <h6> <ul> / <ol> <li> <table> <form> <header> <section> <article> <nav> <footer> <blockquote> <pre> <hr>
Inline 인라인 요소
인라인 요소는 새 줄을 만들지 않고 텍스트 흐름 안에서 콘텐츠 크기만큼만 공간을 차지합니다. 여러 인라인 요소가 나란히 배치되며, width와 height는 콘텐츠에 의해 결정되고 상하 margin은 적용되지 않습니다.
텍스트 흐름 유지 콘텐츠 너비만큼만 차지 width / height 설정 불가 좌우 margin / padding만 유효 내부에 inline 요소만 포함 권장
▶ 라이브 예제 — 모든 요소가 같은 줄에 흐릅니다

이 문장에는 span<span> 으로 강조된 단어와 클릭 가능한 링크<a>, 굵은 텍스트<strong>, 기울임 텍스트<em>가 모두 한 흐름 안에 자연스럽게 섞입니다.

주요 Inline 태그

<span> <a> <strong> <em> <b> <i> <u> <code> <mark> <small> <sub> / <sup> <img> <label> <input> <button>

블록 요소는 수직으로 쌓이고, 인라인 요소는 수평으로 흐릅니다.

<div> — 전체 너비를 차지합니다
<p> 문단 안에 <span> + <strong> + <a> 이 나란히 배치됩니다.
<section> — 다시 새 줄에서 시작합니다

CSS로 display: block / display: inline / display: inline-block을 지정하면 기본 동작을 바꿀 수 있습니다. inline-block은 인라인처럼 흐르면서도 width, height 설정이 가능합니다.
