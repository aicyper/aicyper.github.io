1 Border — 경계선 종류

속성값설명
solid실선. 가장 기본적이고 많이 쓰이는 경계선
dashed점선(직사각형 대시). 구분선·분리선에 자주 사용
dotted점선(원형 점). 부드러운 느낌의 구분선
double이중 실선. 선의 두께가 최소 3px 이상이어야 보임
groove홈이 파인 3D 효과 (inset 느낌)
ridge돌출된 3D 효과 (outset 느낌)
inset요소 전체가 눌린 것처럼 보이는 3D 효과
outset요소 전체가 튀어나온 것처럼 보이는 3D 효과
none경계선 없음 (기본값, 레이아웃 공간도 차지하지 않음)
hidden경계선 숨김 (테이블 충돌 시 none과 다르게 동작)

2 Margin — 외부 여백

Margin은 요소의 바깥쪽 여백입니다. 인접한 요소와의 거리를 조절하며, 배경색이 적용되지 않습니다. 빨간 점선 영역이 margin 영역입니다.

속성설명
margin-top위쪽 외부 여백
margin-right오른쪽 외부 여백
margin-bottom아래쪽 외부 여백
margin-left왼쪽 외부 여백
margin단축 속성 (상 우 하 좌 순서)
property

margin-top

요소의 위쪽에 외부 여백을 추가합니다.

margin-top: 30px;
부모 영역
content
property

margin-right

요소의 오른쪽에 외부 여백을 추가합니다.

margin-right: 60px;
부모 영역
content
property

margin-bottom

요소의 아래쪽에 외부 여백을 추가합니다.

margin-bottom: 30px;
부모 영역
content
property

margin-left

요소의 왼쪽에 외부 여백을 추가합니다.

margin-left: 60px;
부모 영역
content
shorthand

margin (전체)

상하좌우 모두 동일한 여백을 설정합니다.

margin: 20px;
부모 영역
content
shorthand

margin (상하 / 좌우)

첫 번째 값은 상하, 두 번째 값은 좌우 여백입니다.

margin: 10px 40px;
부모 영역
content

3 Padding — 내부 여백

Padding은 요소의 안쪽 여백입니다. 배경색이 padding 영역까지 채워집니다. 초록 점선 영역이 padding이며, 안쪽 어두운 영역이 실제 content입니다.

속성설명
padding-top위쪽 내부 여백
padding-right오른쪽 내부 여백
padding-bottom아래쪽 내부 여백
padding-left왼쪽 내부 여백
padding단축 속성 (상 우 하 좌 순서)
property

padding-top

콘텐츠 위쪽에 내부 여백을 추가합니다.

padding-top: 32px;
content
property

padding-right

콘텐츠 오른쪽에 내부 여백을 추가합니다.

padding-right: 60px;
content

padding-bottom

콘텐츠 아래쪽에 내부 여백을 추가합니다.

padding-bottom: 32px;
content
property

padding-left

padding-left: 60px;
content
shorthand

상하좌우 모두 동일한 내부 여백을 설정합니다.

content
shorthand

padding (상하 / 좌우)

첫 번째 값은 상하, 두 번째 값은 좌우 내부 여백입니다.

4 CSS Box Model — 박스 구조

모든 HTML 요소는 margin → border → padding → content의 네 겹으로 이루어진 박스 모델을 따릅니다.

content
영역설명
content실제 텍스트·이미지 등 내용이 들어가는 영역. width/height로 조절
paddingcontent와 border 사이의 내부 여백. 배경색 적용됨
borderpadding 바깥을 둘러싸는 경계선
marginborder 바깥쪽 다른 요소와의 간격. 배경색 없음
box-sizing

box-sizing: border-box (권장)

width에 padding과 border까지 포함해 계산하므로 레이아웃 관리가 훨씬 쉬워집니다.

*, *::before, *::after { box-sizing: border-box; }

5 Box Shadow — 그림자

box-shadow: offset-x offset-y blur spread color;

콤마(,)로 구분하여 여러 그림자를 중첩할 수 있습니다. inset 키워드를 앞에 붙이면 내부 그림자로 전환됩니다.

값설명
offset-x그림자의 수평 위치 (양수: 오른쪽, 음수: 왼쪽)
offset-y그림자의 수직 위치 (양수: 아래쪽, 음수: 위쪽)
blur-radius흐림 반경. 값이 클수록 그림자가 흐려짐 (기본값 0)
spread-radius그림자 확장 반경. 양수면 커지고 음수면 작아짐 (기본값 0)
color그림자 색상 (rgba 권장)
inset키워드. 외부 그림자 대신 내부 그림자로 렌더링
box-shadow

기본 그림자

오프셋과 블러를 지정한 가장 기본적인 형태

box-shadow: 4px 4px 10px rgba(0,0,0,0.6);
기본 그림자
box-shadow

Spread — 외곽선 효과

spread 값만 사용해 요소 주위에 테두리처럼 표현

box-shadow: 0 0 0 6px #e8ff47;
spread 외곽선
box-shadow

inset — 내부 그림자

그림자가 요소 안쪽으로 들어가 눌린 느낌

box-shadow: inset 4px 4px 12px rgba(0,0,0,0.8);
inset 그림자
box-shadow

컬러 글로우

색상 있는 블러로 발광 효과 연출

box-shadow: 0 6px 24px rgba(232,255,71,0.35);
컬러 글로우
box-shadow

다중 그림자

쉼표로 구분해 여러 그림자를 동시에 적용

box-shadow: 4px 4px 0 #ff6b6b, 8px 8px 0 #47c5ff;
다중 그림자
box-shadow

소프트 엘리베이션

큰 blur로 카드가 떠있는 듯한 깊이감 표현

box-shadow: 0 20px 60px rgba(0,0,0,0.7);
소프트 엘리베이션
box-shadow

네온 글로우

여러 단계의 블러를 겹쳐 네온 발광 효과 구현

box-shadow: 0 0 10px #47c5ff,
  0 0 30px #47c5ff55,
  0 0 60px #47c5ff22;
네온 글로우
box-shadow

none — 그림자 없음

그림자를 제거할 때 사용 (hover 등 상태 변경 시 활용)

box-shadow: none;
그림자 없음
