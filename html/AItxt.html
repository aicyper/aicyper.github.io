HTML 핵심 문자 태그(Text Tags) 소개

1. <b> 태그: 이 텍스트는 굵게 표시됩니다. 단순하게 시각적으로만 두껍게 만들 때 사용합니다.

2. <strong> 태그: 이 텍스트는 매우 중요합니다! 굵게 표시되는 건 같지만, 브라우저에게 내용의 중요성을 강조하는 의미를 담고 있습니다.

3. <i> 태그: 이 텍스트는 기울임꼴로 표시됩니다. 기술적 용어나 외국어, 생각 등을 나타낼 때 주로 사용합니다.

4. <em> 태그: 이 문구는 강조되어야 합니다. 와 비슷하게 기울어져 보이지만, 특정 부분을 말로 강조할 때의 의미를 갖습니다.

5. <u> 태그: 이 텍스트에는 밑줄이 그어집니다. 철자 오류를 지적하거나 고유 명사를 표시할 때 사용합니다.

6. <code> 태그: const message = "Hello World";와 같이 컴퓨터 프로그래밍 코드를 나타낼 때 사용하며, 보통 고정 폭 글꼴로 출력됩니다.

7. <sup> 태그: 숫자의 제곱 표현이나 주석 번호처럼 위첨자를 만들 때 사용합니다. (예: 102 = 100)

8. <sub> 태그: 화학식이나 수식에서 아래첨자를 만들 때 사용합니다. (예: H2O)
