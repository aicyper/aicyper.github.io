03. 단계별 학습 로드맵

현재의 기초 학습을 편입 준비와 장기적인 취업 역량으로 연결하기 위한 계획입니다.

PHASE 01

컴퓨터·코딩 기초

Python 기초, 자료형, 조건문, 반복문, 함수, 파일 처리와 기본 디버깅을 익힙니다.

PHASE 02

네트워크·운영체제

IP, TCP/UDP, DNS, HTTP와 Linux 명령어, 프로세스, 파일 권한을 실습합니다.

PHASE 03

보안 원리·분석

인증과 인가, 암호화와 해시, 로그 분석, 웹 취약점의 원인과 방어 방법을 배웁니다.

PHASE 04

작품·진학 준비

프로젝트를 문서화하고 GitHub에 공개합니다. 지원 대학의 편입 요건과 전형 일정을 확인합니다.

※ 단계별 기간은 현재 학업 일정과 편입 전형에 따라 조정합니다. 편입 자격, 인정 학점, 모집 시기 등은 목표 대학의 공식 모집요강을 반드시 확인해야 합니다.

04. 앞으로 익힐 핵심 기술

기술 이름만 나열하지 않고, 왜 필요한지와 무엇을 할 수 있어야 하는지 함께 기록합니다.

기술쉬운 설명학습 결과 예시상태
Python 데이터를 처리하고 반복 작업을 자동화하는 프로그래밍 언어입니다. 로그 검색기 또는 보안 점검용 작은 스크립트 작성 학습 예정
네트워크 기초 IP 주소와 포트, 프로토콜을 통해 장치 사이의 통신을 이해합니다. TCP 연결과 DNS 조회 과정을 설명하고 패킷을 관찰 학습 예정
Linux 서버에서 널리 사용되는 운영체제와 명령줄 환경을 다룹니다. 파일·사용자 권한을 확인하고 로그에서 이벤트 검색 학습 예정
웹 보안 웹 요청, 인증, 입력값 처리 과정에서 발생하는 위험과 방어를 배웁니다. 안전한 실습 환경에서 취약한 코드와 수정 코드를 비교 학습 예정
Git·GitHub 코드 변경 이력을 관리하고 프로젝트와 문서를 공개하는 도구입니다. README, 실행 방법, 테스트 결과가 포함된 저장소 운영 학습 예정
기술 문서 작성 문제, 원인, 해결 과정, 테스트 결과를 다른 사람이 이해할 수 있게 기록합니다. 프로젝트 보고서와 보안 분석 기록 작성 지속 개선
