1. 보안 전문가란?

온라인상에서 발생하는 해킹이나 바이러스 유입 등을 방지하고, 기업이나 개인의 소중한 정보 자산을 보호하는 정보통신 시스템의 수호자입니다.

2. 주요 업무

  • 보안 정책 수립: 시스템과 네트워크의 취약점을 분석하고 방어 체계 설계
  • 침입 모니터링: 실시간으로 외부 해킹 시도를 감시하고 침입 시 즉각 대응
  • 모의 해킹: 직접 시스템을 공격해 보며 약점을 미리 찾아내 보완
  • 디지털 포렌식: 보안 사고 발생 시 원인을 추적하고 증거 수집

3. 필요한 공부 (학습 로드맵)

기초부터 심화까지 단계별 학습이 필요합니다.

  • 기초 컴퓨터 구조 & 운영체제: Windows, Linux 커널에 대한 깊은 이해
  • 네트워크 TCP/IP 프로토콜: 데이터가 오가는 통로와 패킷의 구조 공부
  • 프로그래밍 C, Python: 시스템 취약점 분석과 자동화 툴 제작 역량
  • 보안 기술 암호학 & 웹 보안: SQL Injection, XSS 등 주요 공격 기법 대응

4. 추천 자격증

  • 정보보안기사 / 산업기사 (국내)
  • CISA / CISSP (국제 공인)
  • CEH (화이트해커 인증)

5. 현재 하고 있는 공부

  • HTML5 이동하기
  • CSS
  • JavaScript
