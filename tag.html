🌐 HTML 실습 파일 목록

각 항목을 클릭하면 해당 예제 페이지로 이동합니다.

  • 1. 문자 태그 소개 (AItxt.html)
    b, strong, i, em, code, sup, sub 등 주요 텍스트 태그 설명
  • 2. 제목 태그 (heading.html)
    h1~h6 태그와 p, br, pre 태그의 특징 비교
  • 3. 하이퍼링크 (hiperlnk.html)
    외부 사이트 연결, 내부 문서 링크(북마크), 메일 보내기 기능
  • 4. 이미지 태그 (img.html)
    상대 경로를 이용한 이미지 삽입 및 로딩 방식 설정
  • 5. 이미지 크기 및 경로 (imgsize.html)
    절대 경로와 상대 경로를 이용한 이미지 크기 조절 실습
  • 6. 문단 관련 태그 (KO.html)
    p, br, blockquote, pre 태그를 활용한 문단 구성
  • 7. 메타 정보 설정 (meta.html)
    문서의 키워드, 작성자, 설명 등 meta 태그 구조 이해
  • 8. 문자 스타일 실습 (monza.html)
    기울임꼴, 강조체, 밑줄 등 다양한 문자 스타일 중첩 사용
  • 9. 특수 문자 표시 (sCh.html)
    공백(&nbsp;), 부등호(<, >), 저작권(©) 등 특수 기호 표현
  • 10. 테이블 작성 (table.html)
    table, tr, th, td 태그를 이용한 표 만들기 실습
  • 11. form 작성 (hometag.html)
    form,input 태그를 이용한 사용자가 데이터를 입력하는 내용
